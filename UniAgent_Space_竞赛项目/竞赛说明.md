# A赛道作品说明（可直接改名后使用）

## 作品名称
UniAgent Space——面向大学生学习、科研与就业的多智能体空间

## 作品定位
本作品针对高校学生在学习规划、课程作业、论文研究、文献整理、编程、数据分析、汇报展示、校园沟通、求职和面试等实际需求，构建一个统一入口的多智能体空间。

## 10个智能体
| 编号 | Agent | 场景 | 核心价值 |
|---|---|---|---|
| 01 | 学习规划 | 教育 | 个性化制定学习计划 |
| 02 | 作业辅导 | 教育 | 引导式解题 |
| 03 | 科研论文 | 教育/科研 | 论文选题和结构设计 |
| 04 | 文献综述 | 科研 | 主题聚类和观点比较 |
| 05 | 编程导师 | 企业服务/教育 | Debug和代码讲解 |
| 06 | 数据分析 | 企业服务/教育 | 数据清洗和统计分析 |
| 07 | 演示汇报 | 教育/企业服务 | PPT与答辩设计 |
| 08 | 校园邮件 | 校园服务 | 高质量沟通 |
| 09 | 求职简历 | 企业服务 | 岗位匹配和简历优化 |
| 10 | 模拟面试 | 企业服务 | 交互式面试训练 |

## 技术实现
采用“统一智能体空间 + 独立Agent配置 + 统一运行引擎”的架构。每个Agent拥有独立角色、目标、Prompt、工具说明和测试场景；统一前端负责 Agent 选择、输入、输出和演示。

## 创新点
1. 面向大学生高频真实场景，而不是泛化聊天机器人。
2. 将学习、科研、技术和就业 Agent 放进一个统一空间。
3. 每个 Agent 具有独立任务边界，降低“十个换皮聊天机器人”的问题。
4. 采用真实任务工作流，例如学习计划生成、代码Debug、简历-JD匹配、逐题面试。
5. 支持从演示模式升级到真实大模型模式。

## 价值
帮助大学生降低信息检索、计划制定、代码调试、论文组织、求职准备等任务的时间成本，提高学习和就业效率。
