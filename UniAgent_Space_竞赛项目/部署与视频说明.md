# 你只需要做这几件事

## A. 本地检查
1. 安装 Python 3.11+
2. 解压项目
3. 打开终端进入项目目录
4. 运行：
   `pip install -r requirements.txt`
5. 运行：
   `streamlit run app.py`
6. 浏览器打开显示的地址。

## B. 正式线上版
推荐使用支持 Streamlit 的云端部署平台。
把整个项目上传到 Git 仓库后，选择 `app.py` 作为入口。
在云平台的环境变量/Secrets 中添加：
- OPENAI_API_KEY
- OPENAI_MODEL = gpt-5.6-luna

## C. 竞赛提交页面
“空间地址链接”填写云端部署后的 HTTPS 地址。
“演示视频”控制在5分钟以内。

## D. 演示视频脚本（约3分钟）
0:00-0:20 项目名称和痛点
0:20-0:40 展示10个Agent
0:40-1:15 学习规划Agent：输入课程和考试日期，展示计划
1:15-1:45 编程导师Agent：输入Bug，展示Debug流程
1:45-2:15 数据分析Agent：展示数据分析入口和输出
2:15-2:45 求职简历Agent：展示JD匹配
2:45-3:00 模拟面试Agent：展示逐题提问与评分
最后一句：
“UniAgent Space通过十个独立智能体覆盖大学生学习、科研、技术与就业场景。”
